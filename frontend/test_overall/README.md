# MaskData

MaskData เป็นเว็บแอปสำหรับตรวจหาและปิดบังข้อมูลส่วนบุคคลในข้อความหรือไฟล์ โดยจะแสดงข้อความต้นฉบับและข้อความที่ผ่านการ Mask แบบเทียบกัน

> ใช้สำหรับการสาธิตและทดสอบเท่านั้น ควรหลีกเลี่ยงการใส่ข้อมูลส่วนบุคคลจริงลงในระบบพัฒนา

## สิ่งที่ระบบตรวจหาได้

- หมายเลขบัตรเครดิต
- อีเมล
- หมายเลขโทรศัพท์
- วันเกิด (DOB)
- เลขที่อยู่ (Address)

ระบบยังแจ้งจุดที่ดูเหมือนข้อมูลส่วนบุคคล แต่มีรูปแบบไม่ถูกต้องเป็น Error แยกต่างหาก

## สิ่งที่ต้องมี

- Python 3
- เว็บเบราว์เซอร์ เช่น Chrome หรือ Edge

## วิธีเปิดใช้งาน

เปิด Terminal ในโฟลเดอร์หลักของโปรเจกต์ แล้วเปิดไว้ 2 หน้าต่าง

### 1. เปิด backend

ถ้ายังไม่ได้เปิด virtual environment ให้ใช้:
.\.venv\Scripts\activate.bat

ติดตั้ง dependencies (ทำครั้งแรกครั้งเดียว):
py -m pip install -r backend\requirements.txt

เปิด API:
py -m uvicorn backend.main:app --reload


หากสำเร็จ จะเห็นข้อความ `Uvicorn running on http://127.0.0.1:8000` และสามารถเปิดเอกสาร API ได้ที่ `http://127.0.0.1:8000/docs`

### 2. เปิด frontend

เปิด Terminal ใหม่ในโฟลเดอร์หลักของโปรเจกต์ แล้วรัน:
py -m http.server 5500 --directory frontend
หรือ ใช้ live_server extention เปิด

เปิดเว็บในเบราว์เซอร์:

```text
http://127.0.0.1:5500
```

## วิธีใช้งาน

1. พิมพ์หรือวางข้อความในหน้าแรก หรือกด Import เพื่อเลือกไฟล์ `.txt` หรือ `.csv`
2. เมื่อ Import ไฟล์ เนื้อหาจะปรากฏใน Text area เพื่อให้ตรวจสอบก่อนส่งประมวลผล
3. กดปุ่ม **Mask**
4. หน้าผลลัพธ์จะแสดง Original ทางซ้าย และ Masked ทางขวา
5. อ่านรายการสรุปใต้กล่อง Original เพื่อดูจำนวนข้อมูลส่วนบุคคลและ Error ที่พบ
6. กดไอคอน Copy มุมขวาบนของฝั่ง Masked เพื่อคัดลอกข้อความที่ผ่านการ Mask
7. กดไอคอน Download มุมขวาล่าง แล้วเลือก **TXT** หรือ **CSV** เพื่อดาวน์โหลดผลลัพธ์

## ความหมายของการไฮไลต์

| ลักษณะ | ความหมาย |
| --- | --- |
| พื้นหลังสีเขียว | ตรวจพบและปิดบังข้อมูลส่วนบุคคลแล้ว |
| พื้นหลังสีเหลือง พร้อมเส้นหยัก | พบข้อมูลที่อาจเป็นข้อมูลส่วนบุคคล แต่รูปแบบไม่ถูกต้อง จึงยังไม่ถูกปิดบัง |

## ประเภทไฟล์ที่รองรับ

- `.txt`
- `.csv`

ขนาดไฟล์สูงสุด 2 MB

## ไฟล์ทดสอบ

ไฟล์ตัวอย่างทั้งหมดอยู่ในโฟลเดอร์ `frontend`

| ไฟล์ | รายละเอียด |
| --- | --- |
| `sample-data.txt` | ตัวอย่างขนาดเล็ก พร้อม Error เบอร์โทรศัพท์ 1 จุด |
| `sample-data-100-lines.txt` | ข้อมูลสมมติ 100 บรรทัด สำหรับทดสอบ scrollbar และ Mask |
| `sample-data-100-lines-with-errors.txt` | ข้อมูล 100 บรรทัด พร้อม Error เบอร์โทรศัพท์ 10 จุด |
| `sample-data-100-lines-all-error-types.txt` | ข้อมูล 100 บรรทัด พร้อม Error ครบ Email, Phone, Credit card, DOB และ Address |

## แก้ปัญหาเบื้องต้น

### ขึ้นข้อความว่าเชื่อมต่อระบบไม่ได้

ตรวจสอบว่า Terminal ของ backend ยังเปิดอยู่ และเข้าถึง `http://127.0.0.1:8000/docs` ได้

### ขึ้นข้อความ `No module named uvicorn`

ติดตั้ง dependencies ใน virtual environment ที่เปิดใช้งานอยู่:

```bat
py -m pip install -r backend\requirements.txt
```

### เปลี่ยน CSS แล้วหน้าเว็บยังไม่เปลี่ยน

กด `Ctrl + F5` ในเบราว์เซอร์ เพื่อโหลด CSS และ JavaScript เวอร์ชันล่าสุด

## โครงสร้างโปรเจกต์

```text
backend/     FastAPI และตรรกะตรวจหา/Mask ข้อมูล
frontend/    หน้าเว็บ HTML, CSS, JavaScript และไฟล์ตัวอย่าง
```
